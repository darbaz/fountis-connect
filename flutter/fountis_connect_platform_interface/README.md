# fountis_connect_platform_interface

The common platform interface for the [`fountis_connect`](https://pub.dev/packages/fountis_connect) plugin
(FOUNTIS Connect for Flutter). It holds the abstract `FountisConnectPlatform`, the shared types and the MethodChannel
client the iOS and Android implementation uses.

You do not depend on this package directly. Add `fountis_connect` to your app instead.
